Methodology — how the erosion index, composite score, and confidence are calculated

RUSLE-lite erosion model

A = R × K × LS × C × P — the standard USLE/RUSLE soil-loss equation. Each factor:

  • K — soil erodibility. A real published K-factor. Primary source: Mireye's soil_erodibility_k_factor (NRCS gNATSGO). If null, backfilled live from USDA Soil Data Access (SSURGO tabular database) via a spatial mukey lookup at the exact point.
  • LS — slope length-steepness. McCool et al. approximation: LS = (L / 22.13)^m × (65.41·sin²θ + 4.56·sinθ + 0.065), where θ is slope in radians and the exponent m is 0.5 (slope ≥5%), 0.4 (3–5%), 0.3 (1–3%), or 0.2 (<1%). L (slope length, meters) is not published anywhere as point-queryable data — real RUSLE derives it by tracing flow paths across a DEM, which this app does not do. Instead L is estimated from canopy density and steepness: base length 40m (canopy ≥60%), 70m (≥30%), 130m (<30%), or 100m if canopy is unknown — then scaled ×0.7 if slope >15% or ×1.3 if slope <3%. Flagged explicitly via slope_length_estimated_from_canopy in the raw response, never presented as measured.
  • C — cover-management. Not a certified USDA C-factor table lookup (those require exact crop/cover-type classification). Proxy: C = 1 − (canopy% / 100) × 0.96, pushed toward the bare-soil value if the 5-year NDVI trend is negative. Canopy defaults to a neutral 20% if Mireye and its canopy backup (MRLC NLCD) both return null.
  • R — rainfall erosivity. Not available from Mireye at all, under any circumstance. Computed independently from Open-Meteo's ERA5 archive: mean annual precipitation averaged over the most recent 10 complete calendar years, run through the Renard & Freimund (1994) empirical relationship — R = 0.0483·P^1.610 (P ≤ 850mm) or R = 587.8 − 1.219P + 0.004105P² (P > 850mm) — then divided by 17.02 to convert SI units to the US-customary units SSURGO's K-factor uses. A screening estimate, not a measured isoerodent value.
  • P — support practice. Not modeled. Assumed 1 (no terracing/contouring data source exists for this).

Two numbers come out of this: the relative index (K × LS × C only — the number the composite score actually reads) and, only when R successfully resolves, the absolute estimate (R × K × LS × C × P, in tons/acre/yr). The absolute figure is informational — it is not what drives the composite score's RUSLE contribution. RUSLE requires both slope and K-factor to be non-null; if either is missing, rusle_lite is entirely null — no relative index, no absolute figure, no default substituted.

A point-based heuristic screening score — not derived from or calibrated against any published industry risk standard. Seven independent signals, each contributing points only when real data resolves a non-trivial risk:

Confidence & data completeness

Each of the 7 signals above resolves to exactly one of three states — real risk data, confirmed no-risk (a genuine reading, e.g. an actual 0% wetland fraction), or unknown/unavailable — never a fabricated default. Confidence is a weighted completeness ratio using the same point weights as the score table above (so losing the 3-point RUSLE signal hurts confidence more than losing a 1-point signal like ponding):

confidence = (12 − Σ weights of unavailable signals) / 12 → high ≥0.85, moderate ≥0.5, low <0.5.

A "low risk" verdict built on very little available data will show low confidence rather than reading identically to one confirmed against complete data.

Data sources & fallback strategy

Primary source: the Mireye Earth API (natural_hazard preset plus 13 explicitly requested extra fields). When a specific field comes back null from Mireye, a live backup is queried directly against the same origin government dataset Mireye itself draws from — never a different or lower-quality substitute:

Field(s)Live backup source
K-factor, hydrologic group, shrink-swell class, ponding frequency, farmland classification, restrictive layerUSDA Soil Data Access (live SSURGO tabular query)
SlopeUSGS 3DEP Elevation Point Query Service
Flood zone, coastal hazard flag, base flood elevationFEMA National Flood Hazard Layer (live ArcGIS REST query)
Wetland fraction & acreageUSFWS National Wetlands Inventory (live ArcGIS REST query against a small point-buffer stand-in for the parcel — no real parcel geometry is available)
Tree canopy %MRLC NLCD Tree Canopy Cover (live WMS query)

No fallback exists for landslide susceptibility index or 5-year NDVI change — no free, no-auth, nationwide, point-queryable equivalent dataset exists for either, so these are left as genuine gaps rather than backed by a mismatched proxy. Recent deforestation comes from Global Forest Watch, a supplementary layer entirely separate from Mireye, not a fallback for a Mireye field.

Governing principle throughout: a value is either real (with its source cited), confirmed-absent (a genuine reading that this legitimately doesn't apply here), or explicitly left unavailable — never guessed or interpolated to fill a gap.

Elevation, slope, seismic, wildfire, flood, landslide, soil, and vegetation-trend data via Mireye Earth (api.mireye.com), sourced from USGS, FEMA, NOAA, USACE, USDA/NRCS, and Sentinel-2. Tree-cover-loss history via Global Forest Watch (World Resources Institute). This report is a screening tool, not a substitute for a licensed geotechnical or environmental survey.
